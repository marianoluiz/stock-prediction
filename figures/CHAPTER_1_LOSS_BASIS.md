# Reproducible, data-based Figures 1.2 and 1.3

These replace the older synthetic-price and symmetric-error illustrations. Both PNGs are generated by `SOP1_SOP2_PSEi_Loss_Illustrations_Colab.ipynb` (or the identical `scripts/build_chapter1_loss_figures.py` code) using data/PSE-PSEI_2018-01-01_latest.csv. Run all cells in Google Colab to regenerate the images and the numerical `SOP_loss_curve_values.csv` table.

## Exact basis

- **Source file:** `PSE-PSEI_2018-01-01_latest.csv` from the repository at commit `00996ca77c8bf6c1fc36865ccc74f26277102b90`.
- **SHA-256:** `35bb13112fc537d62697042bb7dd27803816f51254cadad2822ed0e5913d4972`. The notebook stops if the file differs.
- **Observed example:** 31 January 2019 PSEi close-to-close return, `0.0034498711533312854` (+0.345%). It is the first pre-test day after a 252-return warm-up for which the positive return falls between the stated increase and decrease cost coefficients. This selection makes both loss components visible; it is **not** a representative-day or performance claim.
- **Position scale:** `alpha = 1 / std(252 preceding daily returns) = 87.11622517751499`. The example day's return is excluded from this calibration.
- **Candidate forecast grid:** −1% through +3%. These are hypothetical values used to inspect the loss; **no GRU was trained or scored to make these two figures**.
- **Position and cost:** `s = tanh(alpha × forecast)`; starting from a flat previous position, `cost = 0.00296 × max(s, 0) + 0.00396 × max(−s, 0)`.
- **Net simulated one-step return:** `s × observed_return − cost`.
- **MSE:** `(forecast − observed_return)²`.
- **Profit-aware loss:** `−net_simulated_return + λ × MSE`.

The position and cost equations match the numerical operations in `utils/trading.py`; the combined loss matches `training/train.py`. The notebook uses NumPy rather than PyTorch for this one-dimensional, no-training calculation. The plotted y-axis is the numerical loss multiplied by `10,000` for readability; this does not change its minimizer.

## Captions to use in the paper

**Figure 1.2. MSE and profit-aware loss on an observed PSEi return.** For the 31 January 2019 close-to-close return, the curves evaluate MSE-only and profit-aware training losses over a grid of hypothetical return forecasts, using a position scale calculated from 252 earlier observations and the study's simplified asymmetric position-change costs. The curves illustrate why minimizing forecast error and minimizing the cost-adjusted objective need not select the same forecast value. They do not show trained GRU forecasts or test-period performance. *Source: Authors' calculation from the cached PSEi series and implemented loss equations.*

**Figure 1.3. Calibration-weight effect on the illustrative profit-aware loss.** For the same observed PSEi return and candidate forecast grid, the curves show the profit-aware loss at λ = 0, 0.3, 0.7, 1.0, and 2.0 while holding the return, position transformation, and asymmetric cost rule fixed. The figure illustrates how the MSE calibration weight changes the numerical objective; it does not establish how a trained GRU's forecast error, positions, or simulated returns will change. *Source: Authors' calculation from the cached PSEi series and implemented loss equations.*

## Interpretation limit

These are **one-observation illustrations of the implemented loss**, based on a real PSEi return. They show the *question being tested* and the computation behind it; they cannot answer whether either trained model performs better on held-out data. Do not describe the plotted grid as predictions, a backtest, trading profit, or a market-wide finding. The PSEi is an index and the synthetic position/cost calculation is not an executable trade.
