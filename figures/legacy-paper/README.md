# Original synthetic Chapter 1 illustrations

These are the Figures 1.2 and 1.3 embedded in the paper at Git revision
`00996ca`, preserved for traceability. They have been replaced in the current
paper by the PSEi-based loss illustrations. Their original calculation is in
`notebooks/Chapter_1_original_Colab_source.ipynb`.

The old Figure 1.2 is a synthetic actual-price series with noisy values
constructed using the corresponding actual prices. It is not an out-of-sample
forecast. Its inherited title about poor profit is not established by the
displayed price curves. The old Figure 1.3 compares equal squared errors for
predictions 105 and 95 against actual 100. Neither is current experimental
evidence.
